Why model interchange?

No framework is an island. You may train in PyTorch, export to ONNX for inference, hand a model to a TensorFlow pipeline, or share weights with a colleague using SafeTensors. This chapter shows how to move models into and out of the pure-tf-java engine using four standard formats, all implemented natively in Java with zero external dependencies.

The interchange hub: ModelBundle

Every import/export path goes through puretf.serialize.ModelBundle, a framework-agnostic container holding:

  • Named tensors — the weights and buffers, each with a name, shape, dtype (F16/F32/F64/I8/I16/I32/I64/U8/BOOL), and data.
  • Layer manifest — an ordered list of layer types and constructor arguments so the exact Sequential architecture can be rebuilt.
  • Metadata — input dimension, source format, and any format-specific annotations.

The engine's Sequential.saveBundle() produces a bundle with all three pieces. Sequential.loadBundle(bundle) rebuilds a Sequential from the manifest and restores the weights by matching layer index + parameter index.

1 · SafeTensors (native read + write)

SafeTensors is a simple, secure, dependency-free format: an 8-byte length prefix, a JSON header mapping tensor names to dtype/shape/offsets, then the concatenated raw payloads (little-endian, 8-byte aligned). It supports F16/F32/F64/I8/I16/I32/I64/U8/BOOL.

Java API

// write
ModelBundle b = net.saveBundle();
SafeTensors.write(Path.of("model.safetensors"), b);

// read (weights only — no manifest)
ModelBundle back = SafeTensors.read(Path.of("model.safetensors"));

// full round-trip needs the engine bundle (has manifest + inputDim)
Sequential rebuilt = Sequential.loadBundle(net.saveBundle());

Run it

run.cmd safetensors
# or
mvn -q exec:java "-Dexec.mainClass=puretf.demo.SafeTensorsDemo"

Cross-framework

SafeTensors is the recommended interchange format for PyTorch/TensorFlow/ONNX because it is natively supported by Hugging Face Hub, safetensors Python library, and ONNX Runtime. Use the Python bridge: 

# Python: export any framework → safetensors
python scripts/export_to_safetensors.py --torch model.pt --out model.safetensors
python scripts/export_to_safetensors.py --tf model.h5 --out model.safetensors
python scripts/export_to_safetensors.py --onnx model.onnx --out model.safetensors

Then in Java: SafeTensors.read(Path.of("model.safetensors")).

2 · ONNX (native read + write)

ONNX (Open Neural Network Exchange) is the standard for model portability. A model is a protobuf ModelProto containing a graph of nodes and initializers (the weight tensors). Our native reader parses the protobuf wire format and extracts every initializer into the bundle. The writer emits a valid ONNX ModelProto (ir_version 8, opset 13) with initializers and a feed-forward compute graph (Gemm, Conv, Relu, etc.) reconstructed from the layer manifest.

Java API

// write (weights + graph from manifest)
Onnx.write(Path.of("model.onnx"), net.saveBundle());

// read (weights only — initializers)
ModelBundle back = Onnx.read(Path.of("model.onnx"));

Run it

run.cmd onnx
# or
mvn -q exec:java "-Dexec.mainClass=puretf.demo.OnnxDemo"
ONNX import note. The native reader extracts initializers (weights). It does not reconstruct the full compute graph into a Sequential because ONNX graphs can be arbitrary DAGs. For a full engine round-trip, export the engine's own bundle to ONNX (which includes the manifest in the producer metadata), or pair the ONNX weights with a separately stored manifest.

3 · PyTorch (best-effort native + Python bridge)

PyTorch .pt/.pth files are ZIP archives containing a pickled data.pkl (the state dict) and raw storage blobs (data/0, data/1, …). Our best-effort native reader (puretf.serialize.Torch) opens the ZIP, reads the storage blobs, and attempts to decode the pickle to map names → (storage, dtype, shape, offset). It works for standard CPU float32 models saved with torch.save(model.state_dict(), ...). For compressed storages, complex pickles, or GPU models, use the Python bridge: 

python scripts/export_to_safetensors.py --torch model.pt --out model.safetensors
# Then in Java:
ModelBundle b = SafeTensors.read(Path.of("model.safetensors"));

Run it

mvn -q compile "-Dexec.mainClass=puretf.serialize.Torch" exec:java "-Dexec.args=model.pt"

4 · TensorFlow / Keras (best-effort native + Python bridge)

Keras .h5/.weights.h5 files are HDF5 containers. Our best-effort native reader (puretf.serialize.TensorFlow) parses the HDF5 superblock (v1/v2), walks the group structure, and extracts contiguous float32 datasets. It handles the common model.save_weights() output. For SavedModel directories, compressed datasets, or complex dtypes, use the Python bridge: 

python scripts/export_to_safetensors.py --tf model.h5 --out model.safetensors
# Then in Java:
ModelBundle b = SafeTensors.read(Path.of("model.safetensors"));

Run it

mvn -q compile "-Dexec.mainClass=puretf.serialize.TensorFlow" exec:java "-Dexec.args=model.h5"

Putting it together: the recommended workflow

SourceRecommended path
PyTorch .pt/.pth export_to_safetensors.py --torch → SafeTensors.read()
TensorFlow/Keras .h5 export_to_safetensors.py --tf → SafeTensors.read()
ONNX .onnx Onnx.read() (native) or export_to_safetensors.py --onnx
SafeTensors .safetensors SafeTensors.read() (native)
Engine native Sequential.saveBundle() / Sequential.loadBundle()

Complete cross-framework example

// 1. Train a model in PyTorch (external)
// 2. Export to safetensors via Python bridge
//    python scripts/export_to_safetensors.py --torch model.pt --out model.safetensors

// 3. In Java: import weights
ModelBundle b = SafeTensors.read(Path.of("model.safetensors"));

// 4. If you have the architecture manifest (e.g., saved separately or reconstructed),
//    rebuild a Sequential. Otherwise, inspect weights:
for (NamedTensor t : b.tensors()) {
    System.out.println(t.name() + " " + Arrays.toString(t.shape()) + " " + t.dtype());
}

// 5. Export to ONNX for deployment elsewhere
Onnx.write(Path.of("model.onnx"), b);

// 6. Or save engine-native bundle for full reload
Sequential net = Sequential.loadBundle(b); // if manifest available
net.saveBundle().saveTo(Path.of("model.bin"));
