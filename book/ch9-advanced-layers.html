Beyond the MLP

Chapters 3–8 cover the core path built around Dense. But the nn package also ships a full suite of advanced layers — convolutional, recurrent, and attention blocks — implemented from scratch on the same autograd engine. This chapter shows their real constructors and minimal usage.

Convolutional layers

Conv2D slides a bank of learned filters over an image. Images live in NHWC layout (batch, height, width, channels), matching the pixel arrays of IdxDataset. Padding is either Padding.VALID or Padding.SAME. 

Sequential cnn = new Sequential()
        .add(new Reshape(-1, 28, 28, 1))     // flat 784 -> NHWC 28x28x1
        .add(new Conv2D(32, 3, 3, 1, 1, Padding.SAME))  // 32 filters, 3x3
        .add(new ReLU())
        .add(new MaxPool2D(2, 2, 2, 2, Padding.VALID))   // downsample 2x
        .add(new Conv2D(64, 3, 3, 1, 1, Padding.SAME))
        .add(new ReLU())
        .add(new MaxPool2D(2, 2, 2, 2, Padding.VALID))
        .add(new Flatten())
        .add(new Dense(128, Dense.Act.RELU))
        .add(new Dropout(0.15f))
        .add(new Dense(10));

A complete CNN over Fashion-MNIST. The pipeline is Conv2D(32) → ReLU → MaxPool → Conv2D(64) → ReLU → MaxPool → Flatten → Dense(128) → Dense(10) — exactly the architecture this library's original demo used before we swapped it for the faster MLP.

LayerConstructorRole
Conv2D Conv2D(filters, kh, kw, sh, sw, Padding) learnt filter bank over NHWC images
MaxPool2D MaxPool2D(kh, kw, sh, sw, Padding) max-downsample, adds translation invariance
AvgPool2D AvgPool2D(kh, kw, sh, sw, Padding) mean-downsample (smoother than max)
GlobalAveragePooling new GlobalAveragePooling() reduce each feature map to one number (regularizes)
Upsample2D Upsample2D(factorH, factorW) nearest-neighbour upscale (generative nets)
ZeroPad2D ZeroPad2D(top, bottom, left, right) explicit zero padding
NHWC throughout. Because pixels load as float[count][rows*cols], flatten then reshape restores the spatial grid: Reshape(-1,H,W,C). This mirrors Keras's Reshape((H,W,C)) and keeps every conv op consistent.

Recurrent layers

Recurrent layers process sequences. Input is [batch, time, features]. By default (returning only the final state) they feed a following Dense; with returnSequence they output one vector per timestep. 

// return LAST state only - feed a classifier
Sequential rnn = new Sequential()
        .add(new LSTM(64))                     // -> [batch, 64]
        .add(new Dense(10));

// return EVERY timestep - feed another recurrent layer
Sequential bi = new Sequential()
        .add(new LSTM(64, true))               // -> [batch, T, 64]
        .add(new GRU(32, true))
        .add(new Flatten())
        .add(new Dense(10));
LayerConstructorNotes
RNNRNN(units [, returnSequence])plain Elman cell
LSTMLSTM(units [, returnSequence])gated, long-term memory
GRUGRU(units [, returnSequence])lighter gating than LSTM

Attention & embeddings

For transformer-style models, Embedding maps token ids to dense vectors, then attention mixes them. Inputs are integer token ids, so they need a small manual batching path (see the embedding demo in puretf.demo). 

int vocab = 1000, embedDim = 64;
Embedding embed = new Embedding(vocab, embedDim);   // id -> 64-vector

Sequential decoder = new Sequential()
        .add(new SelfAttention(true))              // causal self-attention
        .add(new Flatten())
        .add(new Dense(10));
LayerConstructorNotes
EmbeddingEmbedding(vocab, dim)trainable lookup table
SelfAttentionSelfAttention([causal])single-head self-attention
MultiHeadAttentionMultiHeadAttention(heads [, causal])multi-head (parallel) attention
PositionalEncodingnew PositionalEncoding()adds sin/cos position signal

Normalization & regularization

LayerConstructorRole
BatchNorm1DBatchNorm1D([momentum, eps])normalize features within a batch (MLP/CNN pre-activation)
BatchNorm2DBatchNorm2D([momentum, eps])normalize per-channel for NHWC feature maps
LayerNorm1DLayerNorm1D([eps])normalize per-sample over features (transformer-friendly)
DropoutDropout(p)randomly zero activations while training

All of these persist through saveTo/loadFrom; BatchNorm's running statistics are carried by saveState/loadState.

Ordering hints

Typical stacks. CNN vision:
Reshape → Conv2D → BatchNorm2D → ReLU → MaxPool → … → Flatten → Dense → Softmax.
Sequence-to-vector:
Embedding → LSTM(units) → Dense → Softmax.
Transformer-ish:
Embedding → PositionalEncoding → MultiHeadAttention → LayerNorm1D → Flatten → Dense. The demos in puretf.demo show each pattern running.
