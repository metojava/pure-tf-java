The Tensor class

A tensor is just a flat float[] plus its shape (an int[] of per-axis sizes). Row-major layout means the last axis varies fastest. Shapes encode everything: a batch of 128 grayscale 28×28 images is [128, 28, 28]; after flattening it's [128, 784]; weights of a dense layer are [fanIn, units]. 

public final float[] data;    // flat values
public final int[]   shape;   // e.g. {2, 3}

Creating tensors

Tensor x   = Tensor.of(flatPixels, 128, 28, 28); // input, no gradient
Tensor w   = Tensor.param(weights, 784, 128);      // trainable parameter
Tensor wg  = Tensor.glorot(new Random(7), 784, 128, 784, 128); // init
Tensor wn  = Tensor.randn(new Random(7), 0.01f, 784, 128);     // gaussian
  • Tensor.of(...) → a leaf that does not track gradient (inputs/constants).
  • Tensor.param(...) → a trainable leaf (its gradient is updated during backprop).
  • Tensor.glorot / Tensor.randn → parameter tensors with good default init.

The forward ops

Operations take one or more tensors and return a new tensor. They look exactly like the math you'd expect: 

x.matmul(w)          // tensor product / dense layer pre-activation
x.addBias(b)         // x + b (broadcast across the batch)
x.mul(y)             // element-wise multiply (e.g. dropout mask, attention)
x.relu() / tanh() / sigmoid()
x.softmax()          // over the last axis
x.reshape(-1, 784)   // reshape; one -1 is inferred
x.permute(0, 2, 1)   // transpose axes
x.meanAxis(0) / x.sumAxis(0)
x.softmaxCE(labels)  // fused softmax + cross-entropy -> scalar loss

Because these are real Java methods, you can trace them to the actual math. For example the dense-layer pre-activation is literally: 

// out[i][j] = sum_k x[i][k] * w[k][j]
for (i) for (k) { float a = x[i*m+k]; if (a==0) continue;
  for (j) out[i*n+j] += a * w[k*n+j]; }

The autograd tape

This is the heart of the library. Each produced tensor registers a backprop closure that knows how to push a gradient back to its parents. A static TAPE records creation order. 

// inside Tensor
private static final List<Tensor> TAPE = new ArrayList<>();
public static void resetGraph() { TAPE.clear(); }

public void backward() {
    grad[0] = 1f;                    // loss gradient = 1
    for (int i = TAPE.size()-1; i >= 0; i--)   // reverse order
        if (TAPE.get(i).backprop != null) TAPE.get(i).backprop.run();
}

So forward builds the graph and computes values; backward walks the tape in reverse, calling each closure to scatter gradients. This is exactly reverse-mode automatic differentiation (backpropagation).

A tiny training step by hand

To see it, we can train one parameter the long way:

Tensor.resetGraph();

Tensor x = Tensor.of(new float[]{1, 2, 3}, 1, 3);   // (3,)
Tensor w = Tensor.param(new float[]{0.5f, 0.5f, 0.5f}, 3);  // (3,)
Tensor b = Tensor.param(new float[]{0f}, 1);

Tensor pred  = x.mul(w).sumAxis(1).addBias(b);   // scalar
Tensor loss  = pred.mse(Tensor.of(new float[]{4f}, 1));

for (Tensor p : List.of(w, b)) p.zeroGrad();     // clear old grads
loss.backward();                                  // fill in w.grad, b.grad

// One SGD step:
Tensor.sgd(List.of(w, b), 0.05f);

After loss.backward(), w.grad holds ∂loss/∂w computed by the tape — no manual chain rule needed.

How it stays fast. The heavy inner loops (matmul, im2col, pooling) are split across the CPU cores by the Par helper, partitioning output slices so each thread writes disjoint data. The autograd tape itself stays strictly sequential.

Vision ops (a preview)

The Tensor class also contains convolution building blocks: im2col, pad2d, maxPool2d, avgPool2d, upsample2d, and bmm (batched matmul). These power the CNN family of layers covered later in the series.

Verifying gradients

The autograd engine gives you gradients for free — but the best habit is proving they're correct. GradChecker compares the analytic gradients from backward() with central finite differences, for any pure function of parameter tensors. Verify a whole op, or a custom layer's core computation: 

import puretf.check.GradChecker;

// does x @ W + b then silu have correct gradients? check every weight element
GradChecker.verify("my layer",
        ps -> GradChecker.sumAll(
                ps[0].matmul(ps[1]).addBias(ps[2]).silu()),
        GradChecker.randn(8, 5),   // x
        GradChecker.randn(5, 3),   // W
        GradChecker.randn(3));     // b
// "ok" printed; throws AssertionError on a mismatch

The built-in GradCheck utility runs this across every core op (run.cmd gradcheck) — a regression net that would catch a broken backprop immediately.
