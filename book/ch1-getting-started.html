Why build neural networks in pure Java?

Normally you'd say "just use TensorFlow". But this project deliberately does the opposite: it re-implements the fundamental pieces of deep learning as plain Java classes you can open and read. The payoff is educational and practical:

  • No native DLLs, no GPU drivers, no heavy dependencies to install.
  • Every operation is a visible for loop over float[] arrays.
  • Training real models (Fashion-MNIST) happens on your laptop CPU in seconds.
  • You can step through training under a debugger to actually see backprop.

What you need

  • Java 17 JDK
  • Maven 3.9+
  • The Fashion-MNIST data files (4 gzip archives) in a folder
  • A 64-bit OS (more CPU cores = faster training)

No TensorFlow, no GPU, and — important — no JFreeChart. Charts are drawn with plain Java2D. The library is 100% pure Java.

The project layout

pure-tf-java/src/main/java/puretf/
├── Tensor.java              # the autograd tensor & math ops
├── Optim.java               # SGD / Momentum / RMSProp / Adam
├── Par.java                 # parallel loop helper (multi-core)
├── data/IdxDataset.java     # loads Fashion-MNIST IDX files
├── nn/                      # layers, sequential models, metrics
│   ├── Layer.java           # base class of all layers
│   ├── Sequential.java      # stacks layers and runs training
│   ├── Dense / Dropout / Flatten / Reshape ...
│   └── Metrics / History / LrSchedule / EarlyStopping ...
├── chart/                   # pure-Java2D PNG/window charts
└── demo/                    # runnable Fashion-MNIST demos

Loading Fashion-MNIST

IdxDataset reads the standard IDX archives (the gzipped ones *-idx*-ubyte.gz). It exposes two records: 

Images(count, rows, cols, float[][] pixels)   // rows*cols values per image, 0..1
Labels(count, int[] labels)                   // the class id per image
var trI = IdxDataset.loadImages(dir + "train-images-idx3-ubyte.gz");
var trL = IdxDataset.loadLabels(dir + "train-labels-idx1-ubyte.gz");

int n     = trI.count();      // 60000
int rows  = trI.rows();       // 28
float[] first = trI.pixels()[0];   // 784 values in [0,1]

int label0 = trL.labels()[0]; // class of the first image

Your first model

A Sequential is a list of layers applied in order. Here is a minimal classifier for Fashion-MNIST. Notice you never declare the input size — the first batch of data teaches each layer its fan-in automatically. 

import puretf.data.IdxDataset;
import puretf.nn.*;

var trI = IdxDataset.loadImages("..." + "train-images-idx3-ubyte.gz");
var trL = IdxDataset.loadLabels("..." + "train-labels-idx1-ubyte.gz");
var teI = IdxDataset.loadImages("..." + "t10k-images-idx3-ubyte.gz");
var teL = IdxDataset.loadLabels("..." + "t10k-labels-idx1-ubyte.gz");

Sequential net = new Sequential()
        .add(new Flatten())
        .add(new Dense(128, Dense.Act.RELU))
        .add(new Dense(10));               // 10 classes, no activation

History hist = net.fitHistory(trI.pixels(), trL.labels(), 10,
        5,            // epochs
        128,          // batch size
        new Optim.Adam(0.0015f),
        LrSchedule.cosine(0.0015f, 0.0002f, 5),
        0f,           // validation split (0 = none)
        null,         // no early stopping
        true);        // print progress

net.saveTo(Path.of("fashion-mlp.bin"));
System.out.println("saved");

That's it. Five epochs on the full 60k set finish in well under a minute on a modern CPU and reach roughly 87–88% test accuracy.

Building and running

cd C:\Users\dell\Desktop\b\pure-tf-java
mvn -q compile exec:java -Dexec.mainClass=puretf.demo.FashionMnistDemo
True to its name. Every number in the code is a plain float in a plain float[]. There is nothing magical hidden behind a JNI call — the whole engine is a few thousand lines of readable Java.
