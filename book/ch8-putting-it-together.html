A complete program

This is the real CnnFashionMnistDemo minus the chart, rewritten to be self-contained: load → build → train (Adam + cosine) → evaluate → report → save. It's the full MLP we benchmarked. 

import java.nio.file.Path;
import puretf.Optim;
import puretf.data.IdxDataset;
import puretf.nn.*;

public final class MlpHalfMNIST {

    private static final String[] NAMES = {
        "T-shirt", "Trouser", "Pullover", "Dress", "Coat",
        "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot"
    };

    public static void main(String[] args) throws Exception {
        String dir = "C:\\Users\\dell\\Desktop\\data\\fashion";

        // 1. Load data
        var trI = IdxDataset.loadImages(dir + "train-images-idx3-ubyte.gz");
        var trL = IdxDataset.loadLabels(dir + "train-labels-idx1-ubyte.gz");
        var teI = IdxDataset.loadImages(dir + "t10k-images-idx3-ubyte.gz");
        var teL = IdxDataset.loadLabels(dir + "t10k-labels-idx1-ubyte.gz");
        System.out.println("loaded " + trI.count() + " train / " + teI.count() + " test");

        // 2. Build the model (slightly complex MLP + dropout)
        Sequential net = new Sequential()
                .add(new Flatten())
                .add(new Dense(128, Dense.Act.RELU))
                .add(new Dropout(0.2f))
                .add(new Dense(64, Dense.Act.RELU))
                .add(new Dense(10));

        // 3. Train with Adam + cosine annealing
        History hist = net.fitHistory(trI.pixels(), trL.labels(), 10,
                5, 128,
                new Optim.Adam(0.005f),
                LrSchedule.cosine(0.005f, 0.0007f, 5),
                0f, null, true);

        // 4. Evaluate + build a confusion matrix
        double[] eval = net.evaluate(teI.pixels(), teL.labels(), 10);
        int[][] conf = new int[10][10];
        float[][] logits = net.predict(teI.pixels());
        for (int i = 0; i < teI.count(); i++) {
            int p = Metrics.argmax(logits[i]);
            conf[teL.labels()[i]][p]++;
        }

        // 5. DL4J-style report
        Metrics.printReport(eval[0], eval[1], conf, NAMES);

        // 6. Save
        net.saveTo(Path.of("fashion-mlp.bin"));
        System.out.println("saved to fashion-mlp.bin");
    }
}

Expected outcome on the full set (5 epochs, LR 0.005, cosine): about 87–88% test accuracy at ~4 s/epoch, memory footprint tiny.

API quick reference

Data

APIPurpose
IdxDataset.loadImages(path)returns Images(count, rows, cols, pixels)
IdxDataset.loadLabels(path)returns Labels(count, labels)

Model construction

APIPurpose
new Sequential().add(layer)...chain layers in order
Dense(units, Act.RELU|TANH|SIGMOID|NONE)fully-connected layer
Dropout(p)dropout for regularization
Flatten / Reshape(...)shape manipulation
build(inputDim)force lazy weight init (like Keras build)
summary()print param counts per layer + total

Data helpers

APIPurpose
new Dataset(X, Y)wrap features + labels
ds.split(frac) / ds.shuffle(seed)train/val split; seeded shuffle (views, no copies)
ds.batches(n)iterate mini-batches of x()/y()
ds.subsample(k)evenly-spread subset for fast experiments

Training

APIPurpose
fitClassifier(X, Y, classes, epochs, batch, lr, verbose)quick train, returns result
fitHistory(X, Y, classes, epochs, batch, opt, sched, valSplit, earlyStop, verbose)full control, returns History
evaluate(X, Y, classes)double[]{loss, acc}
new Optim.Adam(lr) / Momentum / RMSPropoptimizers
LrSchedule.cosine / constant / step / exponentialLR schedules

Evaluation & persistence

APIPurpose
Metrics.printReport(...)scores + confusion + per-class metrics
Metrics.printDl4jMatrix(conf)DL4J-style per-cell output
Metrics.printReportWithChart(...)report + pure-Java2D prediction grid
Metrics.topKAccuracy(logits, Y, k)fraction correct within top-k predicted
predict(X) / predictProb(X)logits, or softmax class probabilities
predict(float[]) / predictProb(float[])single-sample inference
predictTopK(X, k)top-k class indices per sample
getWeights() / setWeights(ws)read / write all parameter values
copy()independent deep clone (K-fold, warm restarts)
net.saveTo(Path)save network (weights + structure)
Sequential.loadFrom(Path)restore a saved network

Verifying custom layers

APIPurpose
GradChecker.check(name, build, seeds)numeric vs analytic gradients; verify throws on failure
GradChecker.maxError(build, seeds)largest |analytic − numeric| gap

Where to go next

The core library you've now seen supports everything in Chapters 1–8. The nn package also ships advanced layers (CNN: Conv2D, MaxPool2D; recurrent: LSTM, GRU, RNN; attention: SelfAttention, MultiHeadAttention; plus Embedding, BatchNorm, normalization and more) — see Chapter 9 for their constructors and example stacks. The demos in puretf.demo show each one in action.

Experiment freely. Because everything is ordinary Java, running an experiment is just changing a constructor argument and re-running mvn compile exec:java. The demo also accepts --lr=, --schedule=, --fast and --nochart flags so you can sweep hyperparameters from the command line.
