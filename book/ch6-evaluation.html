How to measure a classifier

Training accuracy tells you the model fit its data. What you actually care about is test accuracy — performance on images it never saw. This chapter shows the library's evaluation helpers: evaluate, Metrics, confusion matrices, and the pure-Java2D prediction grid.

Quick evaluation

double[] res = net.evaluate(testX, testY, 10);
// res[0] = cross-entropy loss, res[1] = accuracy

And raw prediction: 

float[][] logits = net.predict(testX);      // [n][10] probabilities
int[] predicted   = net.predictClass(testX); // argmax class per sample

The Metrics class

Metrics builds DL4J-style evaluation reports from a confusion matrix. conf[trueLabel][predictedLabel]. 

import puretf.nn.Metrics;

int[][] conf = new int[10][10];
float[][] logits = net.predict(testX);
for (int i = 0; i < testX.length; i++) {
    int p = Metrics.argmax(logits[i]);
    conf[testY[i]][p]++;
}

double accuracy = (double) correct / testY.length;
Metrics.printReport(loss, accuracy, conf, CLASS_NAMES);
Metrics.printDl4jMatrix(conf);

printReport prints, all in one:

  • Overall loss, accuracy, macro precision / recall / F1
  • The full confusion matrix conf[true][pred]
  • Per-class precision, recall, F1 and support

Interpreting the numbers

MetricMeaning
Accuracyfraction of all predictions that are correct
Precision (per class)of the items predicted as class C, how many really were C
Recall (per class)of the actual class-C items, how many were found
F1harmonic mean of precision and recall
Supportnumber of true examples of that class
Confusion matrices show failure patterns. In Fashion-MNIST the classic error is shirt being confused with pullover / t-shirt / coat — the diagonal will be lower for those classes. Looking at where the off-diagonal mass sits tells you what the model is mistaking and why.

One method that reports + charts

The library ships Metrics.printReportWithChart(...) which prints the full report and renders a pure-Java2D prediction grid (one sample per class, with the true label, predicted label, and per-class accuracy % under each image). 

Metrics.printReportWithChart(loss, accuracy, conf, CLASS_NAMES,
        testX, 28, testY, predicted,
        "Fashion-MNIST - one sample per class",
        true,                       // show a window
        "target/fashion-eval.png"); // also write a PNG

"One sample per class" means it picks the first test image of each of the 10 classes and shows the model's prediction + that class's accuracy underneath. This is a great visual sanity check: correct cases are black/red labels, correct ones green, and the class accuracy % sits right under each image.

The evaluation grid layout

  • Images are drawn 5 per row (2 rows for 10 classes).
  • Each image is scaled up and given rounded corners.
  • Under each tile: the true label, the predicted label, and the class accuracy %.
  • Rendered with plain Java2D — no JFreeChart dependency.
