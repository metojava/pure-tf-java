Why persist a model?

Training costs time. Persistence lets you train once, write the weights to disk, and later load them back for inference — or to keep training — without rebuilding the network from scratch. The library makes this trivial: 

net.saveTo(Path.of("fashion-mlp.bin"));            // one call to save

Sequential loaded = Sequential.loadFrom(Path.of("fashion-mlp.bin"));  // one call to load

Round-trip in practice

// --- train & save ---
Sequential net = new Sequential()
        .add(new Flatten())
        .add(new Dense(128, Dense.Act.RELU))
        .add(new Dense(10));

net.fitClassifier(trI.pixels(), trL.labels(), 10, 5, 128, 0.001f, true);
net.saveTo(Path.of("fashion-mlp.bin"));
System.out.println("saved to fashion-mlp.bin");

// --- later, in a different run ---
Sequential net2 = Sequential.loadFrom(Path.of("fashion-mlp.bin"));
double[] res = net2.evaluate(teI.pixels(), teL.labels(), 10);
System.out.println("loaded accuracy = " + res[1]);

What gets saved

The library serializes enough to fully reconstruct the network:

  • The layer types and their constructor arguments (via typeCode() and specArgs()), so the architecture is rebuilt exactly.
  • The trainable weights of every layer.
  • Any extra buffers a layer needs (for example BatchNorm's running mean/variance, via saveState/loadState).
// Layers participate via hooks on Layer:
public int       typeCode()                    { return -1; }  // -1 = cannot persist
public int[]     specArgs()                    { return new int[0]; }
public void      saveState(DataOutputStream out) {}            // extra buffers
public void      loadState(DataInputStream  in)  {}

A Dense layer, for example, reports typeCode()=1 and specArgs()={units, activationOrdinal}, plus hands over its w and b tensors. On load, the engine recreates each layer from its spec args and copies the weights back in.

Design notes

Binary, not JSON. The format is a compact binary stream (constructor args are int[], weights are float[]), so files are small and fast to read. Because it records the exact layer spec, it also validates that a file loads into a compatible architecture.
Custom layers. If you write your own Layer, give it a unique typeCode() and a matching specArgs(), and it will persist too. Leave typeCode() at -1 only if you never save that layer.

Typical workflow

  1. Train (this is the expensive step).
  2. net.saveTo(path) once.
  3. Ship the .bin file + the library to wherever inference runs.
  4. Sequential.loadFrom(path) and call predict.
Sequential model = Sequential.loadFrom(Path.of("fashion-mlp.bin"));
model.setTraining(false);                  // inference mode
float[][] logits = model.predict(newImage);
