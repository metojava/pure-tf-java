The Layer base class

Every layer extends nn.Layer. It has a clever design property: weights are initialized lazily on the first forward pass, so you never have to declare the input size up front. 

public abstract class Layer {
    public abstract List<Tensor> params();          // trainable tensors
    protected abstract void init(int fanIn);        // create weights once
    protected abstract Tensor apply(Tensor x);      // the transform

    public Tensor forward(Tensor x) {
        if (fanIn == -1) { fanIn = x.shape[x.shape.length - 1]; init(fanIn); }
        return apply(x);
    }
    public void setTraining(boolean training) {}    // Dropout uses this
}

Three things you override: params() (what to optimize), init(fanIn) (create weights when the input width is discovered), and apply(x) (compute the layer output).

Writing your own layer

public final class SimpleDense extends Layer {
    private final int units;
    private Tensor w, b;
    public SimpleDense(int units) { this.units = units; }

    protected void init(int fanIn) {
        Random r = new Random(0);
        w = Tensor.glorot(r, fanIn, units, fanIn, units);
        b = Tensor.param(new float[units], units);
    }
    protected Tensor apply(Tensor x) {
        return x.matmul(w).addBias(b);     // no activation
    }
    public List<Tensor> params() { return List.of(w, b); }
}

Dense — the workhorse (full source)

Dense is out = act(x·W + b). Because weights are initialized lazily, it needs only the number of output units: 

public final class Dense extends Layer {
    public enum Act { NONE, RELU, TANH, SIGMOID }

    private final int units;
    private final Act act;
    private Tensor w, b;

    public Dense(int units) { this(units, Act.NONE); }
    public Dense(int units, Act act) { this.units = units; this.act = act; }

    protected void init(int fanIn) {
        Random rnd = new Random(seed);
        w = Tensor.glorot(rnd, fanIn, units, fanIn, units);
        b = Tensor.param(new float[units], units);
    }
    protected Tensor apply(Tensor x) {
        Tensor z = x.matmul(w).addBias(b);
        return switch (act) {
            case RELU -> z.relu(); case TANH -> z.tanh();
            case SIGMOID -> z.sigmoid(); case NONE -> z;
        };
    }
    public List<Tensor> params() { return List.of(w, b); }
}

Dropout — training vs inference

Dropout randomly zeroes a fraction of activations during training to reduce overfitting. It uses setTraining to behave differently at inference time: 

Sequential net = new Sequential()
        .add(new Dense(128, Dense.Act.RELU))
        .add(new Dropout(0.2f))          // 20% dropped while training
        .add(new Dense(10));

net.setTraining(false);   // before evaluating/predicting
float[][] logits = net.predict(testX);   // dropout removed

Sequential — stacking layers

Sequential applies each layer in order. Its fluent .add(...) API is how you assemble a model: 

Sequential net = new Sequential()
        .add(new Reshape(-1, 28, 28))
        .add(new Flatten())
        .add(new Dense(128, Dense.Act.RELU))
        .add(new Dropout(0.2f))
        .add(new Dense(64, Dense.Act.RELU))
        .add(new Dense(10));

This 6-layer MLP is the "slightly complex" model used throughout this book — Flatten then two hidden Dense layers with dropout, then the output layer. Under the hood Sequential.forward just runs for (Layer l : layers) x = l.forward(x);.

Inspecting the model

Because weights initialize lazily, call build(inputDim) to create them, then summary() to see every layer's parameter count: 

net.build(784);            // force init (input is 28×28 = 784 pixels)
net.summary();

//  Idx Layer (type)                Params
//  ---------------------------------------------
//  0   Reshape                            0
//  1   Flatten                            0
//  2   Dense                          100480
//  3   Dropout                             0
//  4   Dense                            8256
//  5   Dense                             650
//  ---------------------------------------------
//  Total params                      109386
Why Reshape(-1,28,28) + Flatten? This is the engine's way of expressing Keras's Flatten(input_shape=(28,28)). Pixels are loaded already flat (length 784), so the reshape restores a 28×28 view and flatten turns it back into a 784-vector — matching the classic quickstart example exactly.
